<LeadParagraph>Icon buttons have an icon included in them.</LeadParagraph>

## Basic Usage

If children are included with these buttons (usually text), then they render in a style similar to the non-icon buttons.
If no children are included, then they render in the icon-only style.

<Alert>
  For icon only buttons you <strong>must</strong> include an
  <code className="inverse">aria-label</code> property that accurately describes
  the function of the button, so that screen-reader users will know the button's
  purpose.
</Alert>
<Alert>
  For icon buttons with text, an <code className="inverse">aria-label</code> is
  not needed, as the function of the button should be described in the visible
  button text.
</Alert>

## Assign Icon to Variable

If you find JSX being passed in as a prop directly ugly, you can assign an icon to a variable and pass that in as the prop.

```tsx
import React from 'react';

import { IconButton } from 'react-magma-dom';
import { NotificationsOutlinedIcon } from 'react-magma-icons';

export function Example() {
  const icon = <NotificationsOutlinedIcon />;

  return <IconButton aria-label="Notifications" icon={icon} />;
}
```

## Custom Size

Icon buttons have default sizes for small, medium and large icon buttons respectively. However, if a pixel size is specified for an icon itself, that size will take precedence.

```tsx
import React from 'react';

import { IconButton } from 'react-magma-dom';
import { NotificationsOutlinedIcon } from 'react-magma-icons';

export function Example() {
  const icon = <NotificationsOutlinedIcon size={10} />;

  return <IconButton icon={icon}>With Custom Icon Size</IconButton>;
}
```

## Icon Position

Use the optional prop `iconPosition` to position the icon of the button on either side of the text.
The `iconPosition` property takes the values `left` and `right`.

```tsx
import React from 'react';

import {
  ButtonColor,
  ButtonIconPosition,
  IconButton,
  ButtonGroup,
} from 'react-magma-dom';
import { NotificationsOutlinedIcon, InfoOutlinedIcon } from 'react-magma-icons';

export function Example() {
  return (
    <ButtonGroup>
      <IconButton icon={<NotificationsOutlinedIcon />}>Icon Left</IconButton>
      <IconButton
        color={ButtonColor.secondary}
        icon={<InfoOutlinedIcon />}
        iconPosition={ButtonIconPosition.right}
      >
        Icon Right
      </IconButton>
    </ButtonGroup>
  );
}
```

## Leading Icon

The `Icon Button` can be customized using the `leadingIcon` prop, which allows an icon to be placed to the left of the button text.

Note: The `leadingIcon` prop will be ignored when `iconPosition` is set
to `ButtonIconPosition.left`, as it is only intended for using on the left side
of the button.

```tsx
import React from 'react';

import { ButtonIconPosition, IconButton } from 'react-magma-dom';
import {
  NotificationsOutlinedIcon,
  SettingsOutlinedIcon,
} from 'react-magma-icons';

export function Example() {
  return (
    <IconButton
      iconPosition={ButtonIconPosition.right}
      icon={<SettingsOutlinedIcon />}
      leadingIcon={<NotificationsOutlinedIcon />}
    >
      Leading Icon
    </IconButton>
  );
}
```

## Sizes

Sizes for `IconButtons` include `small`, `medium`, and `large`, with `medium` being the default value.

## Shape

Icon only buttons have `shape = round`, by default.

```tsx
import React from 'react';

import { ButtonShape, IconButton, ButtonGroup } from 'react-magma-dom';
import { NotificationsOutlinedIcon } from 'react-magma-icons';

export function Example() {
  return (
    <ButtonGroup>
      <IconButton
        icon={<NotificationsOutlinedIcon />}
        aria-label="Notifications"
      />
      <IconButton
        icon={<NotificationsOutlinedIcon />}
        aria-label="Notifications"
        shape={ButtonShape.fill}
      />
      <IconButton
        icon={<NotificationsOutlinedIcon />}
        aria-label="Notifications"
        shape={ButtonShape.rightCap}
      />
      <IconButton
        icon={<NotificationsOutlinedIcon />}
        aria-label="Notifications"
        shape={ButtonShape.leftCap}
      />
    </ButtonGroup>
  );
}
```

## Full-Width Buttons

The `isFullWidth` property will set the button to display full-width. This property does not have any effect on icon-only buttons.

```tsx
import React from 'react';

import { ButtonIconPosition, IconButton } from 'react-magma-dom';
import { NotificationsOutlinedIcon } from 'react-magma-icons';

export function Example() {
  return (
    <>
      <IconButton icon={<NotificationsOutlinedIcon />} isFullWidth>
        Full-Width Notifications Btn
      </IconButton>
      <br />
      <IconButton
        icon={<NotificationsOutlinedIcon />}
        isFullWidth
        iconPosition={ButtonIconPosition.right}
      >
        Full-Width Notifications Btn
      </IconButton>
      <br />
      <IconButton
        icon={<NotificationsOutlinedIcon />}
        aria-label="Notifications"
        isFullWidth
      />
    </>
  );
}
```

## Event Handling

The `onClick` event will fire when the button is clicked, or when the enter or spacebar key is pressed.
Events do not fire on disabled buttons.

```tsx
import React from 'react';

import { IconButton, ButtonGroup } from 'react-magma-dom';
import { NotificationsOutlinedIcon } from 'react-magma-icons';

export function Example() {
  const [iconButtonCounter, setIconButtonCounter] = React.useState(0);
  const [textIconButtonCounter, setTextIconButtonCounter] = React.useState(0);

  return (
    <>
      <p>
        <strong>Icon Counter: </strong> {iconButtonCounter} |{' '}
        <strong>Text Icon Counter: </strong> {textIconButtonCounter}
      </p>
      <ButtonGroup>
        <IconButton
          icon={<NotificationsOutlinedIcon />}
          onClick={() => {
            setIconButtonCounter(count => count + 1);
          }}
        >
          Click me
        </IconButton>
        <IconButton
          icon={<NotificationsOutlinedIcon />}
          onClick={() => {
            setTextIconButtonCounter(count => count + 1);
          }}
        >
          Click me
        </IconButton>
        <IconButton
          disabled
          icon={<NotificationsOutlinedIcon />}
          onClick={() => {
            setIconButtonCounter(count => count + 1);
          }}
        >
          Click me if you can
        </IconButton>
      </ButtonGroup>
    </>
  );
}
```

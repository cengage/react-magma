## Basic Usage

For expanded page content, the `Pagination` component may be added. `Pagination` takes props for count, which is the total number of navigable indices within the component. Additional functions include `defaultPage`, `isInverse`, and `size`.

```tsx
import React from 'react';

import { Pagination } from 'react-magma-dom';

export function Example() {
  const [page, setPage] = React.useState(1);

  function handleChange(_, pageNumber: number) {
    setPage(pageNumber);
  }

  return <Pagination count={10} page={page} onPageChange={handleChange} />;
}
```

## Page Jump

Set `enablePageJump` to `true` to make the ellipsis interactive. Selecting the ellipsis opens a list of the pages it represents, allowing the user to move directly to one of those pages. Page jump is disabled by default.

Use page jump when the total number of pages is moderate and users have a meaningful reason to choose a specific page. For example, it can be useful when users are returning to a known position in an ordered set of results.

<Alert variant="info">
  Avoid page jump when the result set may contain hundreds or thousands of
  pages. Users are unlikely to know that they need an arbitrary page such as
  page 768, and the resulting list of page choices becomes difficult to use.
  Provide filtering, search, sorting, or an appropriate page size to help users
  narrow the results instead.
</Alert>

```tsx
import React from 'react';

import { Pagination } from 'react-magma-dom';

export function Example() {
  const [page, setPage] = React.useState(10);

  function handleChange(_, pageNumber: number) {
    setPage(pageNumber);
  }

  return (
    <Pagination
      count={20}
      enablePageJump
      page={page}
      onPageChange={handleChange}
    />
  );
}
```

## Responsive Behavior

When the available width cannot contain all of the classic pagination controls, they wrap naturally onto additional lines while retaining their reading and keyboard navigation order.

Drag the lower-right corner of the example to preview how Pagination responds to different container widths.

```tsx
import React from 'react';

import { Pagination } from 'react-magma-dom';

export function Example() {
  const [page, setPage] = React.useState(2);

  function handleChange(_, pageNumber: number) {
    setPage(pageNumber);
  }

  return (
    <div
      style={{
        border: '1px solid #c9d3e1',
        maxWidth: '100%',
        minWidth: '260px',
        overflow: 'auto',
        padding: '16px',
        resize: 'horizontal',
        width: '700px',
      }}
    >
      <Pagination count={10} page={page} onPageChange={handleChange} />
    </div>
  );
}
```

## Simple Pagination

An alternative presentation of `Pagination` is available with the `type` prop when configured as `PaginationType.simple`. This converts the existing structure into a dropdown format, while still utilizing previous and next navigation buttons.

Please note that the `Pagination` props of `numberOfAdjacentPages`, `numberOfEdgePages`, `size`, `showFirstButton`, and `showLastButton` are not applicable to this type.

```tsx
import React from 'react';

import { Pagination, PaginationType } from 'react-magma-dom';

export function Example() {
  const [page, setPage] = React.useState(2);

  function handleChange(_, pageNumber: number) {
    setPage(pageNumber);
  }

  return (
    <Pagination
      count={8}
      type={PaginationType.simple}
      page={page}
      onPageChange={handleChange}
    />
  );
}
```

## Inverse

The `isInverse` property is an optional boolean, that reverses the colors so that the buttons can better appear on a dark background.
The default value is `false`.

```tsx
import React from 'react';

import { Card, CardBody, Pagination, magma } from 'react-magma-dom';

export function Example() {
  const [page, setPage] = React.useState(2);

  function handleChange(_, pageNumber: number) {
    setPage(pageNumber);
  }

  return (
    <Card background={magma.colors.neutral1100} isInverse>
      <CardBody>
        <Pagination
          isInverse
          count={4}
          page={page}
          onPageChange={handleChange}
        />
      </CardBody>
    </Card>
  );
}
```

## Size

`size` allows for changing the scale of the `Pagination` component. Two props are allowed, `medium` and `large`.

```tsx
import React from 'react';

import { Pagination, PageButtonSize } from 'react-magma-dom';

export function Example() {
  const [page, setPage] = React.useState(2);

  function handleChange(_, pageNumber: number) {
    setPage(pageNumber);
  }

  return (
    <Pagination
      size={PageButtonSize.large}
      count={6}
      page={page}
      onPageChange={handleChange}
    />
  );
}
```

## Handle Page Change

`pageChange` passes the active data state of the `Pagination` component.

```tsx
import React from 'react';

import { Pagination } from 'react-magma-dom';

export function Example() {
  const [page, setPage] = React.useState(1);

  function handlePageChange(_, pageNumber) {
    setPage(pageNumber);
  }

  return (
    <div>
      <p>
        <strong>Page </strong>
        <span>{page}</span>
      </p>
      <Pagination onPageChange={handlePageChange} count={4} />
    </div>
  );
}
```

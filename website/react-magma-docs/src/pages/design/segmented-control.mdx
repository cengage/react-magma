## When to Use

A Segmented Control is easy to confuse with Tabs, Toggles, Radio buttons and
Button Groups because they look alike. Ask one question: **does choosing an
option change how the same content is shown, right now?** If yes, use a
Segmented Control. If not, use one of the components below.

## Options

### Size

Segmented Controls come in small, medium (default), and large. Each size matches
the height of the Button of the same size, so the control lines up when placed
next to Buttons in a toolbar. Use medium in most cases.

<figure>
  <img src="../../images/segmented-control/sizes.png" alt=" " />
</figure>

### Content

Segments can show text, an icon with text, or an icon only. Use the same type
of content for every segment in a control.

<figure>
  <img src="../../images/segmented-control/content-types.png" alt=" " />
</figure>

### Full Width

By default, the control is only as wide as its content. Full width stretches it
to fill its container and gives every segment the same width. Use it in narrow
containers such as cards and side panels, and on mobile screens when every
segment still fits on one line.

<figure>
  <img src="../../images/segmented-control/full-width.png" alt=" " />
</figure>

### Inverse

Use the inverse style on dark backgrounds.

<figure>
  <img src="../../images/segmented-control/inverse.png" alt=" " />
</figure>

### Responsive

Keep segments visible when space allows. For familiar choices such as List and
Grid, consider compact icon segments first. When several options or longer
translated labels cannot fit comfortably on one line, use the optional dropdown
presentation. It shows the current selection and marks the selected menu item
with a checkmark.

For example, Day, Week, Month, Quarter, and Year remain visible on a wide screen
and become a dropdown on a narrow screen. Keep the same selection in both layouts.

    alt="Five time-range segments on desktop and the same options in an open mobile dropdown, with Month selected in both."
  />
</figure>

## Usage Guidelines

### Change the view, not the page

Use a Segmented Control to switch between views of the same content, such as a
list and a grid of the same items. To move between separate sections or pages,
use Tabs.

## Common Mistakes

Before using a Segmented Control, check that none of these apply:

- **Using it as navigation.** Moving between pages or sections calls for Tabs.
- **Using it for actions.** Save, Share and Delete are Buttons.
- **Using it as an on/off switch.** A single setting calls for a Toggle.
- **Allowing several selections.** Multiple choices call for a Toggle Button
  Group or Checkboxes.
- **Using it in a form with a Save button.** Choices saved later call for Radio
  buttons.
- **Leaving nothing selected.** One option should always be selected.
- **Adding too many options.** Keep to two to five, and never more than seven.
- **Writing long or mismatched labels.** Use one or two parallel nouns.
- **Mixing icons and text.** Use one type of content for every segment.
- **Placing it far from its content.** Keep it directly above what it changes.
- **Disabling options without explanation.** If an option is unavailable, explain
  why nearby, or remove it.

## Accessibility

- **Give the control a name.** Every Segmented Control needs a label that says
  what it changes, such as "Time range." It can be visible text or hidden for
  screen readers only.
- **Keyboard.** People press Tab to move into the control, the arrow keys to
  change the selection, and Tab again to leave.
- **Icon-only segments.** Each icon needs a text label for screen readers, and a
  tooltip helps sighted users.
- **Selected state.** The selected segment is shown by its fill and shadow. Check
  that the selected option stays clear to people with low vision, and don't rely
  on color alone in custom designs.
- **Motion.** The selected background slides when clicked. It doesn't animate for
  people who have turned on reduced motion.

---

## Related Components

- **Tabs**: move between separate sections of content.
- **Toggle**: turn a single setting on or off.
- **Toggle Button Group**: select one or several formatting options, such as
  text alignment or bold.
- **Radio**: choose one option in a form that is saved later.
- **Select** and **Dropdown**: choose from a longer list of options.
